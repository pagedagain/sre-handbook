# PagedAgain Handbook

A practical SRE handbook for Linux and production incident response.

Published at [handbook.pagedagain.com](https://handbook.pagedagain.com).

## Local preview

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

On Windows PowerShell, activate the environment with `.venv\Scripts\Activate.ps1`.
